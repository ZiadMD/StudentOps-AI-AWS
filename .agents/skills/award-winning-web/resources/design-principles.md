# Award-Winning Design Principles & Benchmarks

Guidelines distilled from award-winning digital experiences (Awwwards SOTD, FWA, Stripe, Linear, Apple, Vercel).

## 1. The Light Mode Craft Benchmark
- **Canvas Base**: `#F8FAFC` to `#FAFAFC` with subtle radial lighting.
- **Card Container**: `#FFFFFF` with double-layered shadow and clean 1px border `rgba(226, 232, 240, 0.8)`.
- **Text Contrast**: `#0F172A` (950) for headings, `#334155` (700) for body, `#64748B` (500) for captions.
- **Accent Trust Blue**: `#2563EB` (Blue-600) with `#1D4ED8` hover and `#DBEAFE` subtle background.

## 2. Bento Grid Principles
- **Hero Module**: Large spans (`col-span-2` or `col-span-3`) containing key interactive workflows.
- **Micro Telemetry**: Secondary spans with quick stats and live status indicators.
- **Dynamic Action Strips**: Quick one-click execution cards with icon containers and keyboard shortcuts.

## 3. Bilingual Typography System
- Headings: `Plus Jakarta Sans` for Latin, `Cairo` for Arabic.
- Telemetry: `JetBrains Mono` with `font-variant-numeric: tabular-nums`.
